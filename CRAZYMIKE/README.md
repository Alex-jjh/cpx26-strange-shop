## 运费、租赁和数据边界

用户没有指定城市、租期或楼层，因此每条记录都写明可成立的采购场景。`shipping.amount: 0` 表示商家公开的条件免邮，不表示任意地址或特殊服务都免费。所有主商品报价都有来源与采集日期；小米普通自营配送使用满 69 元免邮政策。

租赁按商家的实际计费方式保留：投影仪替代款极米 NEW Z6X **10 元/天、3 天起**；mini12 同型号 **30 元/天、1 天起**；跑步机替代款汉臣 T200eco **7.33 元/天，仅有 365 天方案，服务区广州天河**。帐篷替代款是 **50 元包 7 天以内，超期 10 元/天、南京自提**，不能写成 50 元/天。上海练鼓室 **50 元/小时**是到店服务，不是 Roland 设备外借。押金、取还配送与地区条件详见租赁表。

咖啡机另有咖博士 F200 商用替代：**16.67 元/天、30 天起、押金 0.01 元、往返运费自付，限定企业长租**；按公开的 30/60/90/120/180/365 天方案估算，不假定个人可直接承租。原 10 类中，筋膜枪、空气炸锅、健身环和破壁机未取得完整可信的现行租赁条件，具体查询结果与未采用理由见 [补充研究](research/rentals-additional.json)。

未取得可靠报价的项目使用 `no-offer-selected`，不编造金额，也不宣称市场上不存在租赁。无法核验的搜索线索保存在研究记录中，没有写入可计算日价。应用中的 `rentCost` 尊重最低租期和帐篷套餐；它只估算租金，不包括押金或未知配送费用；月租/年租只从公布套餐中选择覆盖所需天数的方案。年租超过已公布的 365 天、小时制到店服务或无明确方案返回 `null`。

`editorialUsage` / `typicalUsage` 是逆向 UX 演示的虚构讽刺文案，`editorialUsageIsMeasured: false`，不是用户调查或商家承诺。所有订单继续标为模拟，没有实际下单、租赁或联系商家。

## 维护与验证

在项目根目录运行：

```bash
python3 CRAZYMIKE/scripts/build_package.py
python3 CRAZYMIKE/validate.py
npm test
npm run build
npm run lint
```

生成脚本从归档基础记录、`research/quotes-updated.json`、新增商品和 `research/rentals-updated.json` / `research/rentals-additional.json` 租赁证据构建交接包，再复制到应用目录。重新采集时应先更新研究输入及其采集日期，再生成并验证；不得只改派生 CSV。更新投影仪价格或必需配件时，同时维护根 `README.md` 路演脚本与 `src/domain/review.test.ts`。
